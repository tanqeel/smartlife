# SmartLife

SmartLife — a no-motivation-required discipline system: daily non-negotiables, streaks, a Fajr-to-Isha timetable, 90-day challenge, focus timer, grouped money tracking (MemoGo-style splits), goals and ideas, notes/tasks, and a free AI Coach (Pollinations keyless → Groq → Gemini BYOK → offline fallback) with learned memory and a weekly summary.

A standalone Progressive Web App. Installable, works offline, auto-saves on device (IndexedDB).

Live: https://tanqeel.github.io/smartlife/
